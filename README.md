# Drama

Prywatna aplikacja na Androida do oglądania short dram (jak DramaBox), z gotową biblioteką.

Źródła: wyłącznie oficjalne kanały YouTube studiów (DramaBox, ReelShort, NetShort i inne).
Filmy odtwarza oficjalny odtwarzacz YouTube wewnątrz aplikacji, więc reklamy YouTube zostają.
Aplikacja stawia na pierwszym miejscu pełne serie w jednym filmie (mniej przerw na reklamy).

- `tools/catalog/` – budowa katalogu (codziennie przez GitHub Actions, tylko metadane).
- `app/` – aplikacja (Kotlin, Jetpack Compose).
